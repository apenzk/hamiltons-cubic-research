(1)  can the audit's asserts fire?
====================================================================================
  DEGREE and LEGS_PER_WEYL are literals; two_r = 12, r = 6 follow.
    assert two_r % 2 == 0  ->  True   (12 % 2, a constant)
    assert r <= 12         ->  True   (6 <= 12, a constant)
    assert r <= 6          ->  True   (6 <= 6, a constant)
  Neither depends on n, on the covariants, or on anything measured.  The
  message on the last one -- 'independence would fail somewhere in [6, 12]'
  -- describes a state that no input to this file can produce.
  The loop prints 'r <= n is X -> diagrams are a basis: X', the same
  boolean twice, at n = 6, 12, 24 where it is True by the same constant.

  The third check, assert lo < 1/n < hi with lo = 1/n - 1/n^2:
    n=       2: lo < 1/n < hi is True   because 1/n^2 = 1/4 > 0
    n=       3: lo < 1/n < hi is True   because 1/n^2 = 1/9 > 0
    n=      12: lo < 1/n < hi is True   because 1/n^2 = 1/144 > 0
    n= 1000000: lo < 1/n < hi is True   because 1/n^2 = 1/1000000000000 > 0
  True for every n >= 1 by 1/n^2 > 0.  It restates the definition of lo, hi.

(a)  ODD f AND THE EMPTY PARTITION
     An up-down path in Young's lattice changes |lambda| by exactly +-1
     each step, so |lambda| after f steps has the parity of f.  Odd f
     therefore cannot end at |lambda| = 0.  Checked by enumeration:
      f  m_empty   m_(1)   m_(2)  m_(1,1)   m_(3)
      1        0       1       0        0       0
      2        1       0       1        1       0
      3        0       3       0        0       1
      4        3       0       6        6       0
      5        0      15       0        0      10
      6       15       0      45       45       0
      7        0     105       0        0     105
     TRUE for lambda = empty, and it is a statement about THAT block only:
     odd f carries blocks of odd |lambda| and they are not empty.
     (And seed(f,n) returns a vector of length n^(f-1) at odd f, which
      apply_diagram cannot consume -- odd f was never runnable anyway.)

     LARGEST entries.  Magnitude is not a rank criterion.  Two things to

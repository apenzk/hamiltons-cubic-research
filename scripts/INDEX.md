# Scripts, the index

*Stored  data is catalogued in [data/README.md](data/README.md).*

**The reusable machinery**, one row each. Reviewer one-offs are in [INDEX-reviewers.md](INDEX-reviewers.md); the split exists because those once reached 527 of 728 entries and buried what is here.

**The directory's invariant:** a module something imports lives in [lib/](lib/); a script nothing imports lives in a sibling subfolder, [runs/](runs/), [pipelines/](pipelines/), [route-b/](route-b/), [misc/](misc/), [reviewers/](reviewers/). Every script does `sys.path.insert(0, 'scripts')` from the repo root, so depth never affects imports.

*Longer descriptions were truncated when this became a table on 2026-08-31; the full prose is in git history.*

| [result_dag_figures.py](misc/result_dag_figures.py) | generates the report's three dependency figures from the record's own citations.

# The planning step is silent

**Work out what you need next without saying so.** The harness asks for that reckoning privately, and a reply that opens by reporting it spends the user's attention on the preparation rather than the result.

**"Privately" in that instruction names WHERE the reckoning happens, not a label to emit.** The listing belongs in reasoning; only the requests belong in the reply. *A reply that prints the list has not followed the instruction more carefully, it has misread which half was addressed to the user.*

**So no reply contains the listing in any wording**, not "Privately", not *"what I need next"*, not *"two things, neither depending on the other"*. **Rewording the opener is the failure repeating itself**, since the defect is the visible list rather than the phrase introducing it. **Lead with the answer or the finding**, and let the requests follow as tool calls.

**The instruction that prompts the narration arrives fresh every turn and cannot be edited from here**, so a correction made in conversation is lost at the next compaction while the prompt is not. That is what this file is for: it is read at session start and sits in context beside the instruction it answers.

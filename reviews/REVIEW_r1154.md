## Item 1, the declarations state their claims: CONFIRMED

- graph_load: hypotheses are `hfg : ∀ i, f i ≠ g i` (loopless) and `hpar : ∀ i, (par f g i).card ≤ 2`. The set `par f g i` holds every edge `j` with `(f j, g j) = (f i, g i)` or `(g i, f i)`, so it contains `i` itself and is exactly the class of edges on the unordered pair of `i`. Its card at most `2` is "multiplicity at most 2". The conclusion sums over `univ.filter (0 < deg u)`, the touched vertices, with coefficient `Fintype.card I + 2`. No weakening.
- deg_other_le states `d_o ≤ (|I| − d_u) + |par i|`, the "avoids `u` or parallel to `i`" step, and load_le combines it into `d_u + ∑_{i ∋ u} d_o / d_u ≤ |I| + 2`, the prose load. amgm is the degree-weighted AM-GM with `p, q > 0`, which deg_pos_f and deg_pos_g supply at each edge.
- counts_bound: `P x, M x ≤ 2` for every ordered pair (only `pairs k`, those with `a < b`, enter the sum), `F c` unrestricted, and `∑_{pairs}(P + M) + ∑ F ≤ r`. Conclusion `(r + 2) ∑ s²`. This is the brief's claim. The leftover multigraph is built with `e x = |P x − M x|` copies of `x` indexed by `Fin 2`, and edges_par proves graph_load's parallel hypothesis for it (edges on one pair `a < b` differ only in the `Fin 2` index, and the reversed orientation is excluded by `a < b`).
- slotCls, clsVal, slotμ_eq_val: I compared the match arms of slotCls with those of slotμ in [L240SlotBasis.lean](../lean/HamiltonsCubic/Results/L240SlotBasis.lean#L620) branch by branch.
  - `a = b` (Cartan): slotμ gives `0`, slotCls gives `none`, clsVal `none = 0`.
  - `a < b`: slotμ gives `pairMu N a b i`, which is `(s_a + s_b)²` when `N.p a = i` and `(s_a − s_b)²` otherwise. slotCls gives `((a, b), decide (N.p a = i))`, and clsVal returns the same two values on `true` and `false`.
  - `a > b`: slotμ gives `pairMu N b a j`, read at the upper index `j`, which lies in block `b`. slotCls gives the key `((b, a), decide (N.p b = j))`, reversed and with the sign read at the same endpoint `j`. clsVal returns `(s_b ± s_a)²`, identical to pairMu's values. They agree.
  - one index blocked (either order): `s_c²` in both, with `c` the blocked index's block. Both free: `0` in both.
- cls_card_le_two: a slot of class `((a, b), t)` has its block-`a` index fixed by `t` (side, from blockOf_spec) and its block-`b` index one of `p_b, q_b`, so the slot lies in the two-element set cand. The injection `ij ↦ ij.1` into cand gives the bound for every finite slot set. cls_lt shows a cross class key has `a < b`, which slot_set_bound uses to confine `P, M` to `pairs k`.
- slot_set_bound: `∑_{ij ∈ S} slotμ ≤ (|S| + 2) ∑ s²` for every finite slot set `S`, obtained by fibering `S` over slotCls and applying counts_bound with `r = |S|`. The count hypothesis is proved from `∑_z cnt z = |S|`, dropping the null class and the pairs outside `pairs k` (which have count `0`). No missing hypothesis.
- kappa_cap: hypotheses are `O Oᵀ = 1`, `Oᵀ O = 1`, `X = O N.X Oᵀ`, `0 < r`, `y j` skew and `inner2`-orthonormal. The conclusion is `∑_j inner2 (y j) (−br X (br X (y j))) ≤ (r + 2) ∑_c N.s c²`. It passes `B = (r + 2) ∑ s²` to rowSum_le_of_slotSets, whose side condition is discharged by slot_set_bound and `|S| ≤ r`. The hypothesis `0 < r` is inherited from exists_c_topSum and costs nothing, since `r = 0` is trivial.
- Scope note: the right side is in the normal form's weights `∑_c s_c²`, a quantity of `N`, and kappa_cap takes `N` and `O` as hypotheses rather than producing them. Reading it as "`κ_r ≤ r + 2` at every unit skew `X`" takes two further steps: a normal form for every skew `X` (skew_normal_form under L240) and the identity `inner2 X X = ∑_c s_c²`. At 38aeff4f the second was untyped and the INDEX row said so. Since da734435 both steps are packaged as kappa_cap_norm, `∑_j inner2 [X, y_j] [X, y_j] ≤ (r + 2) inner2 X X` at every skew `X`. I read its statement (skew `X`, `0 < r`, orthonormal skew `y_j`, no normal form in the hypotheses), which states L237 in `X`'s own norm, and it passes the audit below. Its proof lies outside this brief.
- Vacuity: every hypothesis is satisfiable (a normal form exists at `k = 0` and at any `2k ≤ |ι|`, and orthonormal skew families exist for `r ≤ dim 𝔰𝔬(n)`). For `r` above that dimension `hy` has no solutions and the statement is empty, which is the correct content there.

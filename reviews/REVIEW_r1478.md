## B. Statement fidelity of `specFn_blk`

- **The hypotheses on $g$.** `hpos` fixes $g=0$ on $(0,\infty)$, `hneg` fixes $g(x)=-x$ on $(-\infty,0)$, and `hhom` at $c=0$ gives $g(0)=0$. So $g=\max(-x,0)$ pointwise, and no other function satisfies all three. `hhom` is consistent with that function ($\max(-cx,0)=c\max(-x,0)$ for $c\ge0$) and its only extra content is $g(0)=0$ (the kernel step also uses it at $c=t$, which is then automatic).
- **The multipliers.** `negBlkφ a b = [a = b ∧ a < 0]`, so `schur hn hu negBlkφ H` keeps the entries $\langle e_i,He_j\rangle$ with $\lambda_i=\lambda_j<0$, which is $\sum_{\lambda<0}P_\lambda HP_\lambda$ in the eigenbasis (repeated eigenvalues included). `zeroφ a b = [a = 0 ∧ b = 0]` gives $P_0HP_0$ as an operator on all of $E$. Its spectral function $g(P_0HP_0)$ is $(P_0HP_0)_-$ on $\ker u$ and $0$ on its complement, since $g(0)=0$, which is the record's $(P_0HP_0)_-$. The right-hand side `specFn hn g hu + t • (-schur negBlkφ H + specFn g hP0)` is therefore $u_-+tG_1$ with $G_1=-\sum_{\lambda<0}P_\lambda HP_\lambda+(P_0HP_0)_-$.
- **The quantifier.** `∃ t₀ > 0, ∀ t, 0 ≤ t → t ≤ t₀ → ...`: $t_0=\gamma/(2(\mathrm{hsSq}(H_{\mathrm{blk}})+1))$ with $\gamma>0$ from `exists_gap`, fixed before $t$, positive by `positivity`. `hsSq X` is $\sum_i\lVert Xf_i\rVert^2$ over an orthonormal basis, the squared Hilbert–Schmidt norm. The hypotheses on $g$ are satisfiable (screen below), so nothing is vacuous.
- **`hW`.** `∀ hW : (u + t • blkPart hn hu H).IsSymmetric` quantifies over proofs of a proposition, so by proof irrelevance it is one statement, and the proposition is true: `hu.add ((blkPart_isSymmetric hn hu hH).smul _)` proves it. **Screen, not evidence**: a scratch file instantiating `specFn_blk` with `g := fun x => max (-x) 0`, discharging the three hypotheses and supplying `hW` this way, compiled clean.
- **Proof route.** An eigenvector $v$ of $u+tH_{\mathrm{blk}}$ splits into windows $\Pi_-v,\Pi_0v,\Pi_+v$ of $u$, each again an eigenvector with the same $\mu$ because $u$ and $H_{\mathrm{blk}}$ commute with every $f(u)$. On a nonzero $\Pi_+v$, $\mu\lVert w\rVert^2=\langle uw,w\rangle+t\langle H_{\mathrm{blk}}w,w\rangle\ge(\gamma-\gamma/2)\lVert w\rVert^2$, so $\mu>0$. Symmetrically $\mu<0$ on a nonzero $\Pi_-v$. On $\Pi_0v$, $u$ vanishes and $tP_0HP_0w=\mu w$, so homogeneity gives $g(\mu)=t\,g(\mu/t)$ for $t>0$, with $t=0$ handled separately. `specFn_unique` concludes. Every step is kernel-checked.
- **Hand check, $u=\mathop{\mathrm{diag}}(1,0,-1)$, $H=(h_{ij})$ symmetric.** The eigenvalues are simple, so $H_{\mathrm{blk}}=\mathop{\mathrm{diag}}(h_{11},h_{22},h_{33})$ and $u+tH_{\mathrm{blk}}=\mathop{\mathrm{diag}}(1+th_{11},\,th_{22},\,-1+th_{33})$. Here $\gamma=1$ and $t_0=1/(2(h_{11}^2+h_{22}^2+h_{33}^2+1))$, so $t\lvert h_{ii}\rvert\le\lvert h_{ii}\rvert/(2(h_{ii}^2+1))\le1/4$ and the outer entries keep their signs. Directly, $(u+tH_{\mathrm{blk}})_-=\mathop{\mathrm{diag}}\big(0,\,t\max(-h_{22},0),\,1-th_{33}\big)$. The right-hand side: $u_-=\mathop{\mathrm{diag}}(0,0,1)$, $\sum_{\lambda<0}P_\lambda HP_\lambda=\mathop{\mathrm{diag}}(0,0,h_{33})$, $P_0HP_0=\mathop{\mathrm{diag}}(0,h_{22},0)$ with negative part $\mathop{\mathrm{diag}}(0,\max(-h_{22},0),0)$, so $u_-+tG_1=\mathop{\mathrm{diag}}\big(0,\,t\max(-h_{22},0),\,1-th_{33}\big)$. Equal. Passes.

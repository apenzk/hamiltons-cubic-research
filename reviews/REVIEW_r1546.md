## A. Fidelity

- **A-1. The two evaluations** ([L131Diag.lean:33–43](../lean/HamiltonsCubic/Results/L131Diag.lean), [:60–95](../lean/HamiltonsCubic/Results/L131Diag.lean)). Confirmed. `sharpCross X Y` is ½(sharpOp(X+Y) − sharpOp X − sharpOp Y) ([FoxProduct.lean:264–265](../lean/HamiltonsCubic/Base/FoxProduct.lean)), the polarisation of #, so it is Böhm–Wilking's bilinear X#Y. With `sharpOp_diagOp` giving (w²)_ab on φ_ab at symmetric hollow w, the polarisation is ½((u+v)² − u² − v²)_ab = ½(uv + vu)_ab, as stated. For the identity, the proof swaps `fun X => X` for `diagOp jw` on both sharpOp calls through `sharpOp_congr_on_skew`, legitimate because φ_ab is skew and the two operators agree on skew matrices. Then (u·jw)_ab = r_a − u_ab and (jw·u)_ab = r_b − u_ab give ½(r_a + r_b) − u_ab. By hand, this is L131's Ric(R)∧id = R + R#I − 3Alt(R) on the locus: Ric(diagOp u)_aa = r_a, (Ric∧id)(φ_ab) = ½(r_a + r_b)φ_ab in the half-sum wedge, and Alt vanishes because a diagonal operator has R_abcd ≠ 0 only at {c,d} = {a,b}. So R#I = Ric∧id − R there, matching the Lean formula term by term.
- **A-2. The Ricci representatives** ([L131Diag.lean:104–127](../lean/HamiltonsCubic/Results/L131Diag.lean)). Confirmed. (h∧g)(e_a∧e_b) = ½(h_a + h_b)e_a∧e_b for diagonal h, so `knw h` (h_a + h_b off the diagonal) is 2(h∧g), a scalar multiple, which leaves the eigenvalue unchanged. Σh = 0 is tracelessness. The row sums are (n−2)h_a + Σh = (n−2)h_a, and ½(n−2)(h_a + h_b) − (h_a + h_b) = ((n−4)/2)u_ab, as proved. The diagonal operators of Ricci type are exactly these, since the Ricci part of a diagonal operator is diagonal.
- **A-3. The identity** ([L131Diag.lean:46–57](../lean/HamiltonsCubic/Results/L131Diag.lean), [:130–143](../lean/HamiltonsCubic/Results/L131Diag.lean)). Confirmed. `diagOp_jw_skew` proves diagOp jw X = X at every skew X, the diagonal entries being zero by skewness. `eig_scalar` takes `diagOp jw` in the first slot and the literal identity in the second, both the identity on Λ², and its right side `diagOp jw (phi a b)` is φ_ab. Row sums n−1 give n−1 − 1 = n−2, and this is the record's check id# = (n−2)id ([conventions.md:75](../findings/conventions.md)).
- **A-4. The normalisation.** Confirmed. The layer's # returns I#I = (n−2)I (the jw computation, and `sharpOp_id` which conventions.md cites), the halved Böhm–Wilking product the record uses. With 𝒜 = −2(·#I), the #I entries −1, (m−4)/2, m−2 map to 𝒜's +2, −(m−4), −2(m−2), which are the first three entries of L79's table in the same summand order (Weyl, S²_0, R·Id). `eig_weyl`'s hypotheses (symmetric, hollow, zero row sums) are the layer's `IsWeight` ([Families.lean:153–156](../lean/HamiltonsCubic/Base/Families.lean)), Ricci-flat diagonal operators, which satisfy Bianchi automatically, so they are the diagonal Weyl operators.
- **A-5. The case a = b.** Confirmed. φ_aa = single a a 1 − single a a 1 = 0, so both sides are a scalar times 0. `eig_ricci` and `eig_scalar` close it by `subst hab; simp [phi]`, while `sharpCross_diag_id` and `eig_weyl` need no case split. The statements are true there and carry no content, which is harmless.
- **A-6. The Owed item.** Confirmed with gap. The frame-span step is the right obligation for the three diagonal entries: each of Weyl_n, S²_0 and R·Id is O(n)-irreducible, so the frame orbit of one nonzero diagonal representative spans it, and the equivariance of # under the frame action is in the layer ([WeylFoxEquivariance.lean:74](../lean/HamiltonsCubic/Results/WeylFoxEquivariance.lean), `sharpBil_act`). Carrying the table off the locus also uses linearity of X ↦ X#I, which the Owed wording folds into "carries the table". **Gap 1**: consequence (i)'s fourth entry, #I = 2 on Λ⁴, has no diagonal representative (Λ⁴ lies off the Bianchi locus and is never diagonal in the φ basis), and neither the Owed list at [lean/INDEX.md:478](../lean/INDEX.md) nor the "Not typed" note at [L131Diag.lean:22–23](../lean/HamiltonsCubic/Results/L131Diag.lean) names it. It is load-bearing for the claim the Owed item makes: "Weyl_n is the whole −1 eigenspace" needs every other summand's eigenvalue to differ from −1, the Λ⁴ one included. The previous wording ("which needs consequence (i)'s other eigenvalues") covered it, so the rewrite dropped an obligation.

## A. Fidelity

- **A-1. `Fn`** ([L162Limit.lean:21–22](../lean/HamiltonsCubic/Results/L162Limit.lean)). Confirmed, traced by hand. The block ([second-order.md:2326–2334](../findings/second-order.md)) sets c_p = 3θ₀/(n−2), ρ_eff = √6 − θ₀(n+16)/(2(n−2)), λ = 2/√(9(θ₀ − √(3/2))), C = 2(2n−3)/(n−1), β = λ/(2C), w₀ = (n−4)/n, s₀ = √(c_p + ρ_eff w₀²), F = 4s₀/(√(4βs₀+1)+1)². `Sfun` ([L162Mono.lean:24–25](../lean/HamiltonsCubic/Results/L162Mono.lean)) is c_p + ρ_eff w₀² with θ₀ = q/x, q = √(2(x−1)(x−2)). `lam` ([L162.lean:126–127](../lean/HamiltonsCubic/Results/L162.lean)) uses θ₀ = √(2(n−1)(n−2)/n²), the same quantity for x > 0. `Fn` is 4√(Sfun n)/(√(4·(lam n/(2C(n)))·√(Sfun n) + 1) + 1)², which is F with β and s₀ inlined. `F12` ([L162Value.lean:19–20](../lean/HamiltonsCubic/Results/L162Value.lean)) is the same expression with n written as 12, so `Fn 12 = F12` holds by unfolding. No theorem states that equality, which costs nothing since it is definitional. `Fn` also agrees with the left and right sides of `F_gt_twelve` ([L162Mono.lean:130–133](../lean/HamiltonsCubic/Results/L162Mono.lean)).
- **A-2. `F_tendsto`** ([L162Limit.lean:108–118](../lean/HamiltonsCubic/Results/L162Limit.lean)). Confirmed. It is `Tendsto Fn atTop (𝓝 Finf)` on ℝ. - **A-3. `Finf` and the component limits** ([:25–28](../lean/HamiltonsCubic/Results/L162Limit.lean), [:36–105](../lean/HamiltonsCubic/Results/L162Limit.lean)). The division step in `F_tendsto` has its denominator's nonvanishing proved by `positivity`, so no case is lost.

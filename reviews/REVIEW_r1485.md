## A. Both directions

- **The record's claim** ([route-a.md](../findings/route-a.md) line 81): $d^+\Phi(u;H)=2a\kappa_nF(H)\le0$ "for exactly those $n$ with $\kappa_n\le0$, which is $n\ge12$", read over $n\ge4$ and every tangent $H\in\mathcal W_n$. It has two halves: $n\ge12$ gives $d^+\Phi\le0$ for every tangent $H$, and $4\le n\le11$ gives some tangent $H$ with $d^+\Phi>0$ (the negation of the universal). The identification $\kappa_n\le0\iff n\ge12$ is `kappaPen_neg` ($n\ge12$) with `kappaPen_pos` ($4\le n\le11$).
- **`L17_ge12`** ([L17Phi.lean](../lean/HamiltonsCubic/Results/L17Phi.lean) line 323) states the value $2a\kappa_nF(H)\le0$, and `L17` at $\kappa:=$ `kappaPen n` states that value is the derivative. The pair is the first half, as r1484 B recorded.
- **`L17_converse`** (line 228 of the new file) gives, for $4\le n<12$, an `IsWeyl2` $H$ with `innerOp2 H (u2 h4) = 0` and some $d>0$ with `HasDerivWithinAt` of `fun t => Pcubic2 (u2 h4 + t • H) - kappaPen n * altNormSqOf (specFn hN negPartScalar (opB_path_isSymmetric h4 hH.selfAdjoint t))` at $0$ within `Set.Ici 0`. **That function is `L17`'s, character for character, at $\kappa=$ `kappaPen n`**: the same `u2`, the same one path `u2 + t • H`, the same `opB_path_isSymmetric` proof term feeding `specFn`. The $d$ is obtained from `(L17 h4 hN _ (Wb_tangent h4) (kappaPen n)).1`, so it is $2a\kappa_nF(\mathrm{Wb})$.
- **The existential $d$ is the derivative, not one of several.** A derivative within `Set.Ici 0` at $0$ is unique since that set has unique differentiability there. Screen: `(uniqueDiffWithinAt_Ici (0 : ℝ)).eq_deriv _ h₁ h₂ : d₁ = d₂` compiles against Mathlib. So `L17_converse` says $d^+\Phi(u;\mathrm{Wb})>0$, with no reading in which a different slope exists.
- **`kappaPen_pos` against [L16Statement.lean](../lean/HamiltonsCubic/Results/L16Statement.lean) line 86.** `ThetaSq` is $2(n-1)(n-2)/n^2$ at even $n$ and $2(n-1)(n-3)/((n-2)(n+1))$ at odd $n$, `Theta` its square root, `kappaPen n` $=9(\sqrt{3/2}-\Theta_n)$. By hand: the even branch is $<3/2$ iff $n^2-12n+8<0$, true at $4,6,8,10$ ($n=10$: $1.44$). The odd branch is $<3/2$ iff $n^2-13n+18<0$, true at $5,7,9,11$ ($n=11$: $160/108=1.4815$). `ThetaSq_lt` checks the eight cases by `interval_cases` and `norm_num`, `ThetaSq_nonneg` makes the square root monotone step legal, and `Real.sqrt_lt_sqrt` gives $\Theta_n<\sqrt{3/2}$. Correct, and it is the same `kappaPen` that `L17_ge12` uses, so the two halves split one function of $n$ at $12$.
- **Scope.** Both halves assume $n\ge4$, which is the record's own hypothesis ("in $\mathcal W_n$, $n\ge4$").

## B. The witness `Wb`

- **The bivectors.** `om6Z` 3, 4, 5 are $\varphi_{01}+\varphi_{32}$, $\varphi_{02}+\varphi_{13}$, $\varphi_{03}+\varphi_{21}$ ([L17Deriv.lean](../lean/HamiltonsCubic/Results/L17Deriv.lean) line 55), that is $e_{12}-e_{34}$, $e_{13}-e_{42}$, $e_{14}-e_{23}$ in one-based indices, the anti-self-dual partners of `om6Z` 0, 1, 2 ($e_{12}+e_{34}$, $e_{13}+e_{42}$, $e_{14}+e_{23}$). Under `inner2` $=\tfrac12\operatorname{tr}(X^{\mathsf T}Y)$ each has norm squared $2$, as the docstring says.
- **The coefficients.** `Wb X` $=\sum_a\tfrac{\mu_a}2\langle X,\Omega_a\rangle\Omega_a=\sum_a\mu_a\langle X,\omega_a\rangle\omega_a$ with $\omega_a=\Omega_a/\sqrt2$ unit and `CP2Real.mu` $=(2,-1,-1)/\sqrt6$ ([CP2Real.lean](../lean/HamiltonsCubic/Results/CP2Real.lean) line 172). So `Wb` is `Wc`'s spectrum placed on $a',b',c'$ in place of $a,b,c$: **the orientation-reversed competitor**, unit Hilbert–Schmidt norm like $u$. `opB_Wb` confirms it in the model: `rankSum lamBar vec` with `lamBar` $=(0,0,0,2,-1,-1)/\sqrt6$ against `lam6` $=(2,-1,-1,0,0,0)/\sqrt6$.
- **`Wb_weyl`, the four clauses of `IsWeyl`** ([WeylReal.lean](../lean/HamiltonsCubic/Base/WeylReal.lean) line 126, the real definition with the skew-valued clause first).
  - Skew-valued: a sum of scalar multiples of skew `Om a`. Correct.
  - Symmetric: `Wb_inner` makes $\langle\mathrm{Wb}X,Y\rangle$ symmetric in $X,Y$ termwise. Correct.
  - First Bianchi: `Wb_entry` gives $\langle\mathrm{Wb}\varphi_{ij},\varphi_{kl}\rangle=\sum_a\tfrac{\mu_a}2\Omega_a(i,j)\Omega_a(k,l)$, the two sign flips from `inner2_phi` cancelling. The cyclic sum of $\Omega\otimes\Omega$ is the $\Omega\wedge\Omega$ component, and $\Omega_a\wedge\Omega_a=-\lvert\Omega_a\rvert^2\mathrm{vol}$ is the same for all three ASD forms. `cycZ_indep` checks exactly that on $\mathbb Z$ over all $4^4$ index tuples, by `decide` (kernel, not `native_decide`). `cyc_Om` extends it to $\mathrm{Fin}\,n$ by the padding (every term vanishes when an index is $\ge4$, the case split covering each index). Then $\sum\mu_a=0$ kills it. Correct.
  - Ricci-flat: $\mathrm{Ric}(a,b)=\sum_\alpha\tfrac{\mu_\alpha}2\sum_c\Omega_\alpha(a,c)\Omega_\alpha(b,c)$. Each $\Omega_\alpha$ is a complex structure on $\mathbb R^4$, so $\Omega_\alpha\Omega_\alpha^{\mathsf T}=I_4$, the same for all $\alpha$. `gramZ_indep` checks that by `decide`, `gram_Om` pads it, and $\sum\mu_\alpha=0$ closes. Correct.
- **Tangent.** `Wb_tangent` evaluates `innerOp2` through `innerOp2_eq_trace` as $\operatorname{tr}(\mathrm{opB}\,\mathrm{Wb}\circ\mathrm{uOp})=\sum_\gamma$ `lamBar γ * lam6 γ` $=0$, the supports being disjoint. It is the same pairing `L17`'s `hT` uses. Correct.
- **$F(\mathrm{Wb})>0$, and its value.** `Wb_F_pos` argues by contradiction through [L17Cone.lean](../lean/HamiltonsCubic/Results/L17Cone.lean)'s `F_eq_zero_iff`: $F=0$ forces the Schur compression $P_0HP_0$ to vanish on `asd 0` $=a'/\sqrt2$, but `inner_schur_eigen₂` with the unit $\omega=a'/\sqrt2\in\ker u$ reads $\langle\omega,(P_0HP_0)\omega\rangle=\langle\omega,H\omega\rangle=2/\sqrt6$. Correct, and $F\ge0$ comes from `L17_at_u`. **By hand $F=2/\sqrt6$ exactly**: $H$ vanishes on `vec 1`, `vec 2`, so $H_{22}=H_{33}=0$. $H$ is supported on the ASD span, which lies in $\ker u$, so $P_0HP_0=H$ with ASD eigenvalues $(2,-1,-1)/\sqrt6$, and the sliver $\operatorname{tr}(\Pi_{ASD}H_-)=(0+1+1)/\sqrt6$. Then $d=2a\kappa_n\cdot2/\sqrt6=\tfrac29\kappa_n$, matching the record's kink witness ([route-a.md](../findings/route-a.md) line 95, both $\delta^2$ slopes $-\tfrac29=-2aF$). The file proves positivity only, which is all the converse needs.

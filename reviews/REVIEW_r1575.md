## W1

- C#I_t: A#I_t = 0 (t abelian); P_alpha#I_t = (u_alpha^T I u_alpha) P_alpha = P_alpha since |u_alpha|^2 = |alpha|^2/2 = 1. So zero Cartan block, root scalars mu_alpha. Hence <C#I_t, I_t> = 0, <C#I_t, I_R> = sum 2 mu_alpha = 2x.
- C#I_R: A#I_R has root scalars u_gamma^T A u_gamma. The diagonal terms mu_alpha P_alpha#P_alpha give the Cartan block B = 2 sum mu_alpha u_alpha u_alpha^T (the prose omits it; it enters only through <C#I_R, I_t> = tr B = 2x, which self-adjointness also supplies). The ordered off-diagonal terms give, on R_gamma, (1/2) sum over the pairs {beta, delta} at gamma of (mu_beta + mu_delta), since each unordered pair has coefficient 1 in (C#C)_gamma (L268). Matches the record.
- <C#I_R, I_R> = 2 sum_gamma u_gamma^T A u_gamma + sum_gamma sum_{pairs at gamma} (mu_beta + mu_delta). The first term is 2 tr(A sum u u^T) = 2(m-1) tr A = 4(m-1) y, with sum over positive roots of alpha alpha^T = 2(m-1) I in D_m. For the second: for each neighbour gamma of beta (<beta,gamma> = +-1) exactly one of gamma -+ beta is a root, so beta sits in exactly one pair at gamma; beta has 4(m-2) neighbours, so the sum is 4(m-2) x. Cross-count: R roots times 2(m-2) pairs times 2 members equals R times 4(m-2). W as stated.
- Row 1: <C#C, H> = <C, H>. Gram: ||I_t||^2 = m, ||I_R||^2 = 2R, <I_t, I_R> = 0, <C, I_t> = tr A = 2 sum mu^2 |u|^2 = 2y, <C, I_R> = 2x, q = ||A||^2 + 2y. Consistency check: <C#I_t, C> = 2y = <C, I_t>.
- Screen: on so(8), at each of 32 positive solutions from 400 starts, the directly computed G and L agree with the formulas to at most 3e-12 (idempotency error at most 6e-13); on so(6) likewise to 7e-15.

## W2

- Row 1 of L equals row 1 of G, so row 1 of L - lambda G is (1-lambda)(q, 2y, 2x), and p(lambda) is the determinant with rows (q, 2y, 2x), (2y(1-lambda), -lambda m, 2x), (2x(1-lambda), 2x, W - 2R lambda). Row 1 is constant, so deg p <= 2; comparing lambda^3 coefficients, -det G = -p_2, so p_2 = det G.
- p(1/2), rows (q,2y,2x), (y,-m/2,2x), (x,2x,W-R): q[-(m/2)(W-R) - 4x^2] - 2y[y(W-R) - 2x^2] + 2x[2xy + mx/2] = -(W-R)(qm/2 + 2y^2) - x^2(4q - 8y - m) = -Phi.
- det G = 2Rmq - 8Ry^2 - 4mx^2 is a Gram determinant, positive iff C, I_t, I_R are independent. Uniform mu gives A = 2mu^2(m-1) I, so C is in the span; non-uniform mu makes the root scalars of C non-constant, so C is outside the span. Correct.

## W3

- W3a. On the plane span{C, I_t, I_R} with G > 0, the pencil (L, G) is the compression of the self-adjoint L_C. L e_1 = G e_1 (first columns agree), so C is an eigenvector with eigenvalue 1, and the other two eigenvectors are G-orthogonal to C, that is orthogonal to C in the trace pairing. Their eigenvalues are the roots of p. With p_2 > 0 and p(1/2) = -Phi < 0 the roots are real and one exceeds 1/2; its eigenvector H satisfies H perp C and <C#H, H> = lambda ||H||^2 > 1/2 ||H||^2, which is instability in L264's sense (C is positive definite on all of so(2m), so the support is the whole algebra). At I/c (mu = 1/c, c = 2(m-1)): A = I/c, x = R/c, y = R/c^2, q = N/c^2, W - R = R(m-2)/(m-1) = m(m-2); then (W-R)(qm/2 + 2y^2) = 4m^4(m-1)^2(m-2)/c^4 and x^2(4q - 8y - m) = -4m^4(m-1)^2(m-2)/c^4, so Phi = 0. Screen: 0 to 3e-14 at m = 3..10.
- W3b. The bold sentence places the witness "on a direction of span{I_t, I_R} orthogonal to C". The only such direction is H_0 = x I_t - y I_R (<C, H_0> = 2yx - 2xy = 0), with Rayleigh quotient y(yW - 4x^2)/(m x^2 + 2R y^2). Screen: at every so(8) solution it is -0.097, while the pencil root is 0.5399. So C is not destabilised along any Weyl-invariant direction there. **Correction:** the witness lies in span{C, I_t, I_R} cap C^perp, which is the orthogonal projection of span{I_t, I_R} onto C^perp; it mixes C with the Weyl-invariant elements and is not itself Weyl-invariant. The heading's "along Weyl-invariant directions" and the conjecture's "the instability appearing already along Weyl-invariant directions" need the same correction. **Also:** "decides" in the heading overstates: Phi > 0 is sufficient, while Phi < 0 means p(1/2) > 0, which is compatible with both roots above 1/2. The exact test on this plane is "the larger root of p exceeds 1/2", equivalently Phi > 0 or (Phi <= 0 and the vertex of p above 1/2 with p's discriminant nonnegative).

## W4

The notation "beta ~ gamma" should say unordered.

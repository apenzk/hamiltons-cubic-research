## A. Fidelity

The source is [diagonal-half.md:601](../findings/diagonal-half.md) to line 613, Lemma L178: W ∈ 𝒲_n nonzero, supported on Λ²V with dim V = 4, rank(W : Λ² → Λ²) ≤ 3, gives θ(W) ≤ √(3/2), with equality exactly at W_CP² up to positive scale and an O(n) frame. Step 1 splits W on Λ²V into W⁺ ⊕ W⁻, each self-adjoint and trace-free on a three-space and so of rank 0, 2 or 3, and a total rank at most three kills one.

- **A-1. W_C is the general supported self-adjoint operator.** `eF i` ([L178Reduce.lean:23](../lean/HamiltonsCubic/Results/L178Reduce.lean)) is sq2⁻¹ · Emb G_i Embᵀ, with `G = Sum.elim J K` (line 18). Under the layer's `inner2 X Y = ½ tr(XᵀY)` ([WeylReal.lean:39](../lean/HamiltonsCubic/Base/WeylReal.lean)), ⟨eF i, eF j⟩ = ¼ tr(G_iᵀ G_j), which is δ_ij because each J_a and K_b is orthogonal with four unit entries, J_a ⊥ J_b and K_a ⊥ K_b off the diagonal (the `SUFrame` orth fields), and J ⊥ K (`J_K_orth`). So e is an orthonormal basis of the six-dimensional Λ²ℝ⁴ ⊂ Λ²ℝⁿ. A self-adjoint W supported there (W = PWP for P the projection onto Λ²ℝ⁴) is W = Σ_{i,j} ⟨We_i, e_j⟩ ⟨·, e_i⟩ e_j, which is `WC n C` (line 26) with C_ij = ⟨We_i, e_j⟩, symmetric by self-adjointness. Conversely W_C with C symmetric is self-adjoint and supported there. `WC` is defined on all n × n matrices, but `inner2 X (eF i)` kills the symmetric part of X since eF i is skew (`eF_skew`, line 35), so nothing is added off Λ². Correct.
- **A-2. weyl_blocks.** `IsWeyl` ([WeylReal.lean:126](../lean/HamiltonsCubic/Base/WeylReal.lean)) is the conjunction of bivector preservation, symmetry, `bianchi R i j k l = 0` for all indices and `Ric R a b = 0` for all indices, so `hW.2.2.1` and `hW.2.2.2` ([L178Reduce.lean:119](../lean/HamiltonsCubic/Results/L178Reduce.lean) and line 123) are Bianchi and Ricci, instantiated at embedded indices `E hn x`. `WC_phi_inner` (line 66) gives ⟨W_C φ_ac, φ_bd⟩ = Σ C_ij (eF i)_ca (eF j)_db, and `ric_WC` (line 90) sums c over all of Fin n, which is right: eF vanishes off the embedded block, so the sum collapses to the 4 × 4 product ½ Σ C_ij (G_iᵀ G_j)_xy through `sandwich`. `bianchi_WC` (line 76) reads the three terms at (0,1,2,3) as ½ Σ C_ij cyc2(G_i, G_j). Using only these seventeen scalar equations is legitimate: they are consequences of the hypothesis, and discarding the rest weakens nothing in the conclusion. The count matches the classical decomposition, the trace-free Ricci of a four-dimensional curvature being the Λ⁺ ⊗ Λ⁻ block (nine conditions), the scalar curvature tr A + tr D, and the (0,1,2,3) Bianchi, through ω⁺ ∧ ω⁺ = vol and ω⁻ ∧ ω⁻ = −vol, tr A − tr D. That is the eleven the docstring (line 111) names, and the conclusion (lines 114 to 116) is exactly B = 0, tr A = 0, tr D = 0. The "rank 11" in the docstring is prose from a screen and the proof does not depend on it. Correct.
- **A-3. one_block_zero is step 1.** With B = 0 and A, D symmetric trace-free (line 182), rank C ≤ 3 forces A = 0 or D = 0. The source argues each nonzero block has rank at least 2. The Lean argues the same thing through a nonzero principal 2 × 2 minor in each block (`minor_ne`, line 160), which together give a 4 × 4 principal submatrix of nonzero determinant and so rank C ≥ 4. That is step 1's argument, the rank-one exclusion for a symmetric trace-free 3 × 3 matrix read as "some principal 2 × 2 minor is nonzero". Correct.
- **A-4. C.rank.** With e orthonormal, the coordinate map X ↦ (⟨X, e_i⟩)_i is onto ℝ⁶ from Λ²ℝⁿ and the e_j are independent, so rank(W_C : Λ² → Λ²) = rank C. The hypothesis `C.rank ≤ 3` (line 224) is therefore the source's rank hypothesis for W = W_C. This dictionary is linear algebra and is not typed, which is part of the owed identification, see C-dh.
- **A-5. L178_padded.** Line 223: for `4 ≤ n`, C symmetric, `IsWeyl (WC n C)`, `C.rank ≤ 3` and `C ≠ 0`, `theta (WC n C) ≤ √(3/2)`, with `theta` the layer's P/‖W‖³ ([WeylReal.lean:180](../lean/HamiltonsCubic/Base/WeylReal.lean)). The proof runs `weyl_blocks`, `one_block_zero`, then `WC_split` (line 212, closed by `rfl` because `eF (inl a)` unfolds to CP2Real's `om a` and `eF (inr b)` to `omF asdFrame b`), so W_C is `WMat n A` or `WMatA n D` with the other block zero, and milestones 2 and 3 (`WMat_theta_le`, `WMatA_theta_le`) finish. `C ≠ 0` becomes the surviving block nonzero through `hC`, C = fromBlocks A 0 0 D (line 239). This is L178's inequality on ℝⁿ for V the first four coordinates, stated on the W_C form. The equality clause is neither claimed nor typed.
- **A-6. What stays owed.** Against the source's statement, the Lean leaves exactly three things: (i) a general four-dimensional V, which needs an O(n) change of frame carrying V to the first four coordinates and θ, rank and the Weyl conditions along with it; (ii) the identification of an abstractly given self-adjoint operator supported on Λ²ℝ⁴ with its W_C, which carries rank and self-adjointness across (A-1, A-4); (iii) the equality clause, rigidity up to positive scale and an O(n) frame. [lean/INDEX.md:70](../lean/INDEX.md) lists all three, and the plan ([2026-09-26-lean-L178-padding-plan.md:12](2026-09-26-lean-L178-padding-plan.md)) names (ii). Accurate.
- **A-7. A witness.** C = fromBlocks A 0 0 0 with A = diag(2, −1, −1), CP²'s self-dual spectrum. C is symmetric and nonzero with rank 3, and `WC_split` makes W_C = `WMat n A`, which `WMat_weyl` shows Weyl for symmetric trace-free A. Every hypothesis of `L178_padded` holds, so the theorem is not vacuous. It is also the equality case: θ = √(3/2) there by milestone 1.

If every principal 2 × 2 minor vanishes, a_ii a_jj = a_ij² ≥ 0 for each pair, so 0 = (Σ a_ii)² = Σ a_ii² + 2 Σ a_ij² forces every diagonal entry to vanish (`hsq` and the three `nlinarith` calls, lines 168 to 170), and then 0 − a_ij² = 0 kills the off-diagonal ones (lines 172 to 174). - **The 4 × 4 determinant** (lines 194 to 202). r = (inl i, inl j, inr k, inr l) with i ≠ j and k ≠ l, so the submatrix is block diagonal with the 2 × 2 blocks of A and D (the off blocks vanish by `hB` and `hB'`), and its determinant is the product of the two minors, which Lean expands by Laplace and closes with `ring`. Nonzero by `minor_ne`, so rank 4 by `rank_of_isUnit`, and `rank_submatrix_le` bounds it by rank C, contradicting `hrank` by `omega`. Sound.
- **Hidden hypotheses: none.** Orthonormality of e is not a hypothesis and not needed by the proof, which runs through `WC_split` into the milestone-2 and milestone-3 theorems.

## A. Fidelity

- **A-1. `inner_harmonic`** ([L99Pair.lean:24–49](../lean/HamiltonsCubic/Results/L99Pair.lean)). Confirmed with gap. The encoding: `blockNormSq w part γ` ([L99Statement.lean:318–319](../lean/HamiltonsCubic/Results/L99Statement.lean)) is Σ over ordered pairs (a, b) with a in γ of w_ab², and `innerOp` of two diagonal operators is ½ Σ v_ab w_ab (`innerOp_diagOp`), so a unit block ‖M_γ‖² = 1 scaled by λ_γ has `blockNormSq` = 2λ_γ², which is `hmass`. `hscale` is λ_γθ_γ = θ at edge-carrying blocks, and `hth` is θ_γ ≠ 0. The proof rewrites through `innerOp_indDir` to ½ Σ_γ a_γ `blockNormSq`, substitutes λ_γ = θ/θ_γ at edge-carrying blocks, and shows `blockNormSq` = 0 at the others by `CarriesEdge`'s negation, so the sum runs over the edge-carrying blocks alone, as the record says ([diagonal-half.md:169](../findings/diagonal-half.md)). **Vacuity**: none. At a block with no edge `hmass` forces λ_γ = 0, which is the construction's value (such a block has M_γ = 0 and carries no unit summand), and `hscale` is not asked there. `hth` at those blocks and at empty classes of `C` constrains a free parameter, so θ_γ = 1 satisfies it. At an edge-carrying block `blockNormSq` > 0 (`blockNormSq_pos`), so λ_γ ≠ 0, and at θ > 0 the pair λ_γ = √(`blockNormSq`/2), θ_γ = θ/λ_γ satisfies all three. **Gap**: the header at [L99Pair.lean:9–12](../lean/HamiltonsCubic/Results/L99Pair.lean) says "criticality forces λ_γθ_γ = θ at every edge-carrying block (`scaling_forced`). This file composes the two", and the L99 row at [lean/INDEX.md:428](../lean/INDEX.md) says "composing … `scaling_forced`'s λ_cθ_c = θ". The proof never calls `scaling_forced`. It takes `hscale` as a hypothesis on `lam` and `th`, which are free reals tied to `w` only through `hmass`. `scaling_forced` itself takes the block relation λ²θ_c = θλ as a binder (the L99 statement row at [lean/INDEX.md:429](../lean/INDEX.md) already records that no Q appears), and [L99Statement.lean:94–98](../lean/HamiltonsCubic/Results/L99Statement.lean) says the identification of a block's θ_c with a critical point of its own "needs `Qop` restricted to a block, which no layer builds". So the theorem is the record's identity with θ_c *defined* as θ/λ_c, and that θ_c is M_c's own critical value, with λ_cθ_c = θ forced by `IsCritical (diagOp w) θ`, is a reading. The header should say `hscale` is assumed, and the row should list the reading.

The block ([second-order.md:2326–2334](../findings/second-order.md)) sets c_p = 3θ₀/(n−2), ρ_eff = √6 − θ₀(n+16)/(2(n−2)), λ = 2/√(9(θ₀ − √(3/2))), C = 2(2n−3)/(n−1), β = λ/(2C), w₀ = (n−4)/n, s₀ = √(c_p + ρ_eff w₀²) and F = 4s₀/(√(4βs₀+1)+1)². `Sfun` ([L162Mono.lean:24–25](../lean/HamiltonsCubic/Results/L162Mono.lean)) is c_p + ρ_eff w₀² with θ₀ = q/x and q = √(2(x−1)(x−2)), which is θ₀(n)² = 2(n−1)(n−2)/n². `lam` ([L162.lean:126–127](../lean/HamiltonsCubic/Results/L162.lean)) is the block's λ with the same θ₀. `F12` inlines C(12) = 2·21/11 = 42/11 and β = λ(12)/(2C), and is F with s = √`Sfun` 12, verbatim the left side of `F_gt_twelve` ([L162Mono.lean:130–133](../lean/HamiltonsCubic/Results/L162Mono.lean)), so the bracket and the monotonicity bound the same object. At n = 12, q = √220 and `Sfun` 12 = √220/40 + (√6 − 7√220/60)·4/9 = 4√6/9 − (29/1080)√220, which is `hS`.

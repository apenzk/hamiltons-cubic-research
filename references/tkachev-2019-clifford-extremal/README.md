# Tkachev, On an extremal property of Jordan algebras of Clifford type

| | |
| --- | --- |
| **Source** | [On an extremal property of Jordan algebras of Clifford type](https://arxiv.org/abs/1801.05724) |
| **Identifier** | arXiv:1801.05724; Comm. Algebra 47 (2019) 1057–1066 |
| **Retrieved** | 2026-08-22 |

**Consulted for.** Route T2: whether the hidden Clifford structure on the $\tfrac12$-eigenspace at an extremal idempotent caps its dimension, which would make a symmetry-free maximizer impossible.

**What matters.** Theorem 1.2 and Definition 1.1: for a **unital** Euclidean metrised algebra, every shortest idempotent obeys $|c|^2\le\tfrac12|e|^2$, and equality characterises the Jordan algebras of Clifford type. The proof runs through the conjugation $c\mapsto\bar c=e-c$, which needs the unit outright.

**Verdict.** **Does not apply.** $\mathcal W_n$ has no unit, $L_u=\mathrm{Id}$ would force $\operatorname{tr}(L_u)=\dim\mathcal W_n>0$ against the identity $\operatorname{tr}(L_x)\equiv0$, and the least-squares fit of $L_u$ to $\mathrm{Id}$ returns $\sqrt D$ exactly, the value at $u=0$. The route is closed by its own gate. Recorded because the paper is otherwise about precisely this project's quantity (shortest idempotents, $\theta=1/\|c\|$) and the dividing line is exactly unitality.

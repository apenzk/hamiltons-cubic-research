**Consulted for.** The classification of non-symmetric isotropy irreducible coset spaces $G/K$, in this project's use, the pairs with $G=SO(n)$ or $Spin(n)$, which index the two-eigenvalue critical points $W_{\mathfrak h}\propto\Pi_{\mathfrak h}-\tfrac rN\mathrm{Id}$ of $P$.

**What matters.** Theorem 11.1 and the four tables on pp. 107–110 it refers to: a complete list of the non-symmetric simply connected isotropy irreducible $G/K$. Transcribed in [notes.md](notes.md).

**Verdict.** It supplies the enumeration the two-eigenvalue family needs, and nothing more, it classifies the pairs, and says nothing about $Q$, about $P$, or about which pair maximises anything. The dimension bound this project derives is not in it. The 1968 scan OCRs badly, so the legible copy of the tables is the modern transcription in [lauret-rossibertone-tolcachier-2025-sii-laplace](../lauret-rossibertone-tolcachier-2025-sii-laplace/notes.md).

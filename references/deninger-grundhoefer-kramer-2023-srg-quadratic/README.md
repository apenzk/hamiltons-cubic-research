# Deninger–Grundhöfer–Kramer 2023, Weyl Tensors, Strongly Regular Graphs, Multiplicative Characters, and a Quadratic Matrix Equation

- Christopher Deninger, Theo Grundhöfer, Linus Kramer, [arXiv:2204.02706](https://arxiv.org/abs/2204.02706) (v3, Sep 2023), J. Algebra; math.GR, which is why this programme's geometry-side searches never surfaced it.
- **Studies exactly this record's diagonal criticality equation**: real symmetric hollow $S$ with $\sum_kS_{ik}=0$ and $\sum_kS_{ik}S_{kj}+S_{ij}^2=\theta S_{ij}$ for $i<j$, i.e. $\theta R=R^2+R^\#$ for Einstein algebraic curvature tensors whose eigenvectors are the coordinate bivectors $e_i\wedge e_j$.

## Statements that matter

- The pinching-family / cone-invariance method for the ODE $\dot W=Q(W)$.
- Establishes the dynamical setting in which the conjecture is posed.
- **Lemma 2.1**: $R+R\,\#\,I=(n-1)R_I+\tfrac{n-2}2R_{\mathrm{Ric}_0}=\mathrm{Ric}\wedge\mathrm{id}$, with $\langle W\rangle$ in the kernel. This is the record's per-index relations (A) and (B) in one line, and Schur on the multiplicity-free $S^2_B$ says there is no third. See [notes](notes.md).

## Verdict

Cone-invariance arguments are **dynamical** (ODE-invariance) rather than static, and no static analogue of the single-point comparison this problem needs has been built. Recorded as a checked-and-insufficient reduction tool.

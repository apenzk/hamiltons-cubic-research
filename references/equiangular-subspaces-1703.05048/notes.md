# Balla, Sudakov, Equiangular subspaces in Euclidean spaces, transcribed

> **Theorem 1.** Let $k,n\in\mathbb N$ with $k\le n$, let $d$ be an angle distance on $\mathrm{Gr}(k,n)$ and let $\alpha>0$. Then $N^d_\alpha(k,n)\le\binom{\binom{n+1}2+k-1}{k}$.

*p. 3. $N^d_\alpha(k,n)$ is the maximum size of a set of $k$-subspaces of $\mathbb R^n$ pairwise at angle distance $\alpha$. The proof uses that $(\cos\alpha)^2$ is an eigenvalue of $U_i^{\mathsf T}U_jU_j^{\mathsf T}U_i$ for every pair.*

> **Theorem 2.** For any $k,n\in\mathbb N$ with $k\le n$, there exists a set $H\subseteq\mathrm{Gr}(k,kn)$ with $\lvert H\rvert=N(n)^k$ [of pairwise-equiangular subspaces].

*p. 5. The lower-bound construction.*

**Why it does not bear on the record's question.** Both theorems count subspaces. The record's question is what saturating $\sum_i\lVert P_{\Pi_i}D\rVert^2\le\tfrac53\lVert D\rVert^2$ forces on $D$ for THREE fixed planes, which is a statement about the frame operator and not about how many planes there can be.

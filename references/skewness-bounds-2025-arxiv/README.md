# De Michele, De Bartolo. Skewness-Kurtosis: small samples and power-law behavior

- [arXiv:2506.16906v1](https://arxiv.org/abs/2506.16906), math-ph, 20 June 2025. Retrieved 2026-09-15 as [skewness-2506.16906.pdf](https://arxiv.org/abs/2506.16906), text in [skewness-2506.16906.txt](https://arxiv.org/abs/2506.16906).
- **Consulted for**: the classical attribution of the sample-skewness bound, which is the vector form of [L225](../../findings/second-order.md), raised by [r947](../../reviews/REVIEW_r947.md).
- **What matters**: equation (4) and references [18], [19].
- **Verdict**: **a secondary source naming the primary ones.** It states $\lvert S\rvert\le\frac{n-2}{\sqrt{n-1}}$ for sample skewness and credits Wilkins (1944) and Kirby (1974). With $g_1=\sqrt k\sum\lambda_i^3$ on the unit trace-free sphere this is L225's bound, so L225's vector statement is a classical fact and the record's contribution is the proof route and its use on matrix blocks.
- **Primary source**: Wilkins (1944) at Project Euclid answered a command-line fetch with an HTML challenge page on 2026-09-15, so the attribution rests on this secondary citation until a copy is retrieved.

## Consulted for

Step 8 sweep, alongside Cheng–Wang 2508.11226. Generalises the cone condition to $k$-partial sums: $k^{-1}(\lambda_1+\cdots+\lambda_k)\ge-\theta(n,k)\bar\lambda$ for $k\le\lfloor(n+2)/4\rfloor$ forces flat or spherical space form. Supersedes Dai–Fu and Chen–Wang thresholds.

## Verdict

Same transfer mechanism as Cheng–Wang, one parameter wider. The $k$-family of constants $\theta(n,k)$ is a calibration set for any branch-1-shaped estimate: each $(n,k)$ pair is a proved instance of "bottom partial sum controls the Bochner cubic". Notes in [notes.md](notes.md).

# References

Sources consulted by the proof programme, one subfolder per source. Each holds a `README.md`, the index card: link, identifier, what it was consulted for, and the verdict, plus `notes.md`, the transcription, where the source has been read.

**A source with no `notes.md` is a source nobody has read.** The skill treats that as a marker: a paper filed with only its PDF reads as consulted while its theorems stay invisible.

[CARTAN-SEARCH.md](CARTAN-SEARCH.md) is a search record rather than a source: it lists every candidate weighed in the hunt for a citable statement of Cartan's classification, which of the four facts each one carries, and the one fact. Casimir data for the exceptional pairs, that remains unsourced.

# Ge–Tang, transcription

> **Theorem 1.1.** Let $B_1,\dots,B_m$ be $n\times n$ real symmetric matrices. Then $\sum_{r,s=1}^m\lVert[B_r,B_s]\rVert^2\le\big(\sum_{r=1}^m\lVert B_r\rVert^2\big)^2$, where the equality holds if and only if under some rotation all $B_r$'s are zero except two matrices which can be written as $\mu\begin{pmatrix}0&1\\1&0\end{pmatrix}\oplus0$ and $\mu\begin{pmatrix}1&0\\0&-1\end{pmatrix}\oplus0$. (p. 2)

**Read for the record.** The equality case is the pair of Pauli-type matrices on a common $2$-plane, the least commuting configuration, so the theorem measures how non-commuting a family can be and bounds nothing cubic. The record's use of this family is the pair-mass ceiling of the 2026-09-13c sweep.

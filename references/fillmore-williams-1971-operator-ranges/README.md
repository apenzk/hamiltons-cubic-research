# Fillmore, Williams, On operator ranges

- **Source**: P. A. Fillmore and J. P. Williams, *On operator ranges*, Advances in Mathematics **7** (1971), 254–281.
- **Link**: [home.agh.edu.pl/~rudol/Operat/FilmoreWilliams.pdf](https://home.agh.edu.pl/~rudol/Operat/FilmoreWilliams.pdf), the copy filed here. The publisher record is Advances in Mathematics 7 (1971) 254-281, doi 10.1016/0001-8708(71)90006-3, whose landing page refuses automated requests.
- **Consulted for**: the range-additivity fact that L180(3) uses without argument, for positive semidefinite $A,B$, $\operatorname{range}(A+B)=\operatorname{range}A+\operatorname{range}B$.
- **Verdict**: **carries it, in the general Hilbert-space form.** Theorem 2.2 states $\mathcal R(A)+\mathcal R(B)=\mathcal R\big((AA^*+BB^*)^{1/2}\big)$; applied to $A^{1/2},B^{1/2}$ in finite dimensions it is exactly the fact L180(3) needs.

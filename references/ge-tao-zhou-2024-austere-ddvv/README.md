# Ge, Tao, Zhou, Normal scalar curvature inequality on a class of austere submanifolds

- arXiv: [2410.17761](https://arxiv.org/abs/2410.17761), published Math. Z. 2026. Retrieved 2026-09-24.
- Consulted for: the I73 seven-frame lemma (bracket total of an orthonormal 7-frame in $\mathfrak{so}(n)$), as a source of DDVV constants that depend on the family's structure.
- Statements that matter: Theorem 1.1 (constant $\tfrac12$ on $Q(p,q)$), Theorem 1.2 (constant $\tfrac{d-1}{2d}$ on $Q(n-1,1)$, $d$ the span dimension).
- Verdict: symmetric matrices in off-diagonal block subspaces, so it does not bound $T$ for skew frames. Theorem 1.2's span-dependent constant has the same shape as [L238](../../findings/second-order.md)'s rank factor $1-\tfrac1r$, and its class $Q(n-1,1)$ is the symmetric analogue of the pencil frame $u\wedge w_i$. The method is Ge–Tang's weighted-simplex argument.

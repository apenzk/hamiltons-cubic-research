## How to use this file

1. **Read this index in full.** It is short by design and it is the only file a cycle must read whole.
2. **Open one finding file**, the one the map below names for the subject in hand. Do not read the others.
3. **Before claiming anything is new, check the value table below**, then `grep -rn "<value>" findings/` to confirm. Three refutations on record came from points already in the file, all missed because the search used the vocabulary of the construction rather than the value.
4. **Write findings back into the file that owns the subject**, not into this index. This index carries one line per result and no mathematics.

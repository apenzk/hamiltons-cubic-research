## 3. The forcing argument (item 2)

Link by link.

1. **Strict dominance.** ell_2 = lambda_2 + 1/2 >= 1/2 > 0 and ell_1 - ell_2 = lambda_1 - lambda_2 + 1 >= 1 > 0. This holds for every dominant lambda, including the edges (item 3 of the standing list): at lambda = 0, ell = (3/2, 1/2). On the wall lambda_1 = lambda_2 ((2,2), (3,3), (4,4), (6,6)), ell_1 - ell_2 = 1. On the wall lambda_2 = 0 ((4,0), (3,0), (2,0), (6,0), (5,0), (1,0), (0,0)), ell_2 = 1/2. The rho-shift moves both walls strictly inside the chamber. The passage writes "for a dominant B_2 weight ell_1 > ell_2 > 0", which labels ell as the weight. Read as "for dominant lambda, ell = lambda + rho satisfies", it is correct.
2. **Recovery.** e_1 = p_2 by definition and e_2 = (p_2^2 - p_4)/2 by I5. {ell_1^2, ell_2^2} is the root multiset of t^2 - e_1 t + e_2. Since ell_1 > ell_2 > 0, ell_1^2 > ell_2^2 orders the roots, positive square roots give ell, and lambda = ell - rho.
3. **From eigenvalues to p_2, p_4.** C_2's eigenvalue is p_2 - 5/2 (Section 0). For C_4, I1 and I3 give eigenvalue gamma(C_4)(ell) with gamma(C_4) W-invariant of degree <= 4. By I2 the W-invariants of degree <= 4 are spanned by 1, p_2, p_2^2, p_4 (degrees 2 and 4 generators, no odd-degree invariants since -1 is in W). So gamma(C_4) = c p_4 + b p_2^2 + beta p_2 + gamma_0. Given the value of p_2, the eigenvalue determines p_4 exactly when c != 0.

"Whether the leading term alone determines the eigenvalue": it does not. gamma^{-1}(p_4 + p_2) has leading term p_4 and eigenvalue p_4 + p_2. It does determine the separating power of the pair, because every lower-order W-invariant is a polynomial in p_2 (see 3.W1 for the candidate this raised). **CONFIRMED.**

**CONFIRMED**, with "the" read as "any".
